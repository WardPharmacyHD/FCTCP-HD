# CP Portal HD User Guides

These guides cover the daily workflow and reporting functions in **Ver. 2.0**.

## Getting started

1. Select your pharmacist profile and sign in with your PIN.
2. Check the **Shift Date** and **Designated Ward** in the top bar.
3. Open the appropriate function from the main menus.
4. Use **Back** to return to a previously visited page.

## Daily Ward Activities

### Daily Activities & CP3

Record your task commitment, attending physicians, ward rounds, clinical clerking and counselling activity. Review the live CP3 report before saving a draft or finalizing the shift.

- **Save Draft** preserves work in progress.
- **Finalize & Lock** completes the shift and locks its activity controls.
- Confirm the ward and date before finalizing or printing.

### Pharmaceutical Care Issues (PCI)

Enter the patient details, issue category, description and recommendation using the available form fields. Review the logged records and use the available edit or delete controls when corrections are required.

### Drug Information (DI)

Record drug information enquiries and their responses. Review the enquiry log and filters to find an existing record.

### Follow-Up Required

Review outstanding follow-up items and update their completion status. Unresolved items can carry forward into later shift reports.

### Daily Attendance

Review your duty calendar and enter attendance information using the available calendar controls.

## RETEN

Reporting functions in this menu retain their existing administrator access restrictions.

### MANUAL RETEN INPUT

1. Select the month and ward.
2. Enter the CP1, CP2 and Bedside Dispensing figures.
3. Save the entry and review the recorded figures.
4. In **Monthly Reten Summary by Ward**, select the month to review ward totals.
5. Use **Export Excel** to download the ward summary.

The entry list and ward summary refresh after saving or deleting a manual Reten entry.

### Reports & PF 6.3(b)

Select the available report filters, review the summary and use the report's print or export controls.

### Monthly CP3 Batch Archive Exporter

Select the target ward and month. Generate the monthly batch PDF and review the browser print preview before printing or saving as PDF.

### Multi-Month Roster Batch

Open the dedicated roster page. Select the start and end months, review the team roster and choose the Excel or PDF export control.

## Admin / Settings

- **Register New Pharmacist** creates a pharmacist profile with a ward, username, PIN and role.
- **Database / Connection Tools** contains endpoint testing, API configuration and local data backup.
- **Active Registered Directory** lists pharmacist profiles and available management actions.
- **Change PIN** updates your own security PIN and is available to signed-in pharmacists.

Profile management and database functions remain restricted to administrators.

## Information Center

- **User Guides** explains how to use the portal.
- **Documentation** contains version history, changelogs and reference notes.
- **Announcements** contains portal notices.

Choose **Refresh** to reload the selected information page after content has been updated.
