# Documentation

## CP Portal HD — Ver. 2.0

### Application layout

- Retained the dark slate theme with a compact identity bar and separate menu row.
- Grouped navigation into Daily Ward Activities, RETEN, Admin / Settings and Information Center.
- Used green, red, gold and blue for the four menu groups.
- Moved Designated Ward beside Shift Date and highlighted both controls in red.
- Kept the top bar visible and added Back navigation between workspaces.
- Displayed one selected workspace at a time.

### Daily workflow

- Corrected PCI terminology to **Pharmaceutical Care Issues**.
- Retained Daily Activities & CP3, attendance, PCI, DI and follow-up workflows.

### Reporting and administration

- Grouped PF 6.3(b), manual Reten input and batch exporters under RETEN.
- Made Multi-Month Roster Batch a dedicated page.
- Renamed and emphasized **MANUAL RETEN INPUT**.
- Moved Monthly Reten Summary by Ward into Manual Reten Input.
- Separated pharmacist registration, database tools and the active directory into individual pages.
- Moved Change PIN into Admin / Settings.

### Information Center

- Added User Guides, Documentation and Announcements pages.
- Loaded their content from Markdown files maintained in GitHub.
- Included Refresh controls and a message when content cannot be loaded.

## Version history

### Ver. 2.0

Navigation and layout revamp, isolated workspaces, reporting menu reorganization and the Information Center.

### Earlier portal

The previous interface used individual workflow tabs and a combined administration workspace. Historical version numbers and release dates have not been assigned here.

## Reference notes

The Information Center is informational. It does not change CP3 calculations, report datasets, API endpoints or pharmacist access roles.
